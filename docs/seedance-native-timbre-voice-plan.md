# Seedance Native Timbre Voice — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Repurpose the `seedance_native` engine so Seedance generates the spoken voice natively from in-prompt dialogue, in a consistent polished Indian-English timbre anchored to one short ElevenLabs clip, with per-clip script-fidelity verification.

**Architecture:** ElevenLabs becomes an internal-only oracle (line-duration timing + a single ~6s timbre anchor); every speaking clip is generated by Seedance `reference-to-video` with the *same* anchor as `audio_url` and the line in the prompt ("voice timbre references Audio 1"). A per-clip Scribe transcript gate enforces the script and falls back to `syncso` on drift. Per-beat `voice_mode` (`on_camera` / `background_vo` / `silent`) decides delivery.

**Tech Stack:** Python 3.11, asyncio, pydantic, pytest + pytest-asyncio, ElevenLabs SDK (eleven_v3 + Scribe `scribe_v1`), EvoLink Seedance (`seedance-2.0-reference-to-video`), ffmpeg.

## Global Constraints

- Final output audio is **100% Seedance-native** — no ElevenLabs audio in the muxed video (ElevenLabs is timing oracle + timbre donor only).
- Consistency scope = **within one video** (fresh anchor per run; no persistence).
- Engine id stays `"seedance_native"` (repurposed, not a new id).
- Accent = **polished, neutral, urban Indian-English**, multilingual EN+HI; explicitly **not** exaggerated/stereotypical.
- Script fidelity threshold = normalized word-overlap **≥ 0.70**, **1 retry**, then per-clip fallback to `syncso`.
- Test idiom: pytest + `@pytest.mark.asyncio`; inject mocks via `_client=`; build beats with `types.SimpleNamespace`; assert on both return values and `fake.<method>.call_args.kwargs`. Use dummy-key `Settings` via each test file's local `_settings()` helper.
- Live EvoLink work is **blocked until credits are topped up** (51.34/108). Tasks 1–9 are mock-tested and need no credits; Task 10 (live validation) is the credit-gated step.

```python
# app/voice.py — add near the top-level helpers (after imports)
import re as _re

_PARALINGUISTIC = _re.compile(r"[\(\[][^)\]]*[\)\]]")  # (sighs), [laughs]

def _words(text: str) -> set[str]:
    cleaned = _PARALINGUISTIC.sub(" ", text or "").lower()
    return {w for w in _re.split(r"[^a-z0-9ऀ-ॿ]+", cleaned) if w}

def script_fidelity(transcript: str, expected: str) -> float:
    """Normalized word-overlap (Jaccard) of transcript vs expected line.

    Strips bracketed/parenthetical paralinguistics the native model adds
    ((sighs), [laughs], (birds chirping)). Empty `expected` (silent beats)
    scores 1.0 — there is no line to violate. Devanagari range included so
    Hindi lines score too.
    """
    we = _words(expected)
    if not we:
        return 1.0
    wt = _words(transcript)
    if not wt:
        return 0.0
    return len(we & wt) / len(we | wt)
```

```python
# app/voice.py — module-level helper
import subprocess as _subprocess

def _extract_audio(src, dst) -> None:
    """16k mono wav for STT."""
    _subprocess.run(
        ["ffmpeg", "-y", "-i", str(src), "-vn", "-ac", "1", "-ar", "16000",
         str(dst)], check=True, capture_output=True,
    )
```

```python
# app/voice.py — method on ElevenLabsVoice
    async def transcribe(self, *, media_path) -> str:
        """ElevenLabs Scribe STT on a media file's audio track.

        Used by the native-timbre QA gate to verify each generated clip said
        exactly the scripted line. Runs the blocking SDK call in a thread.
        """
        from pathlib import Path
        media_path = Path(media_path)
        wav = media_path.with_suffix(".stt.wav")
        await asyncio.to_thread(_extract_audio, media_path, wav)
        def _call():
            with open(wav, "rb") as fh:
                return self._client.speech_to_text.convert(
                    model_id="scribe_v1", file=fh)
        resp = await asyncio.to_thread(_call)
        return (getattr(resp, "text", "") or "").strip()
```

```python
# app/pipeline.py — near _beat_mode
def resolve_voice_mode(beat) -> str:
    """Effective voice_mode for a beat (planner value wins; else derived).

    on_camera     = talking_head speech (lip-synced native voice)
    background_vo = broll/off-screen shot that still carries a spoken line
    silent        = reaction hold OR broll with no dialogue (ambient only)
    """
    explicit = getattr(beat, "voice_mode", None)
    if explicit in ("on_camera", "background_vo", "silent"):
        return explicit
    if getattr(beat, "beat_kind", "speech") == "reaction":
        return "silent"
    has_line = bool((getattr(beat, "dialogue_text", "") or "").strip())
    if beat.shot_type == "talking_head":
        return "on_camera" if has_line else "silent"
    return "background_vo" if has_line else "silent"
```

```python
# app/pipeline.py — near the other audio helpers
def build_timbre_anchor(vo_audio_path, work_dir, uploader, *,
                        seconds: float = 7.0) -> str:
    """Cut the first `seconds` of the (paced) VO as the run's ONE timbre
    fingerprint and upload it once. The same URL is passed as audio_url to
    every speaking clip — that is what keeps the native voice consistent.
    The VO itself never reaches the output (oracle + donor only)."""
    from pathlib import Path
    anchor = Path(work_dir) / "timbre-anchor.wav"
    slice_audio(vo_audio_path, 0.0, seconds, anchor)
    return uploader.upload(str(anchor))
```

```python
    line = _strip_tags(beat.dialogue_text or "").strip()
    return (
        "Filmed on an iPhone front camera, handheld with a slight natural "
        "sway, even soft diffuse daylight on the face. "
        f"{_SKIN_TEXTURE_CLAUSE} "
        f'The creator looks at the lens and says exactly: "{line}" — {tone}. '
```

```python
# app/pipeline.py
async def verify_clip_fidelity(voice, clip_path, expected, *,
                               threshold: float = 0.70):
    """Transcribe a generated clip and score it against the scripted line.
    Returns (passed, transcript). Empty `expected` (silent beats) auto-passes
    via script_fidelity == 1.0."""
    from app.voice import script_fidelity
    transcript = await voice.transcribe(media_path=clip_path)
    return script_fidelity(transcript, expected) >= threshold, transcript
```
